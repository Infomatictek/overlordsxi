# Implementation details for the proposed kits

Use these rulings wherever a job card relies on a native event or on the meaning of a vulnerability. They define behavior for new work only. Existing completed kits keep their handlers.

## Events, ownership and fallback behavior

| Soul | Resolution detail |
|---|---|
| Zealot | Refund once per attack-round sequence after first landed regular main-staff hit. No refund on enemy immunity/zero damage, WS, counters or bonus hits. Minimum 1 MP cost per divine spell. Divine Seal remains pending through cancellation, is spent on a completed damaging cast and expires after 20s. Only its next ordinary divine spell bonus is affected. Use the target's actual light resistance. |
| Astromancer | Serialize empowered hits on the target's current spawn generation. Compute bonus = base × (multiplier − 1), clamp the bonus to the boss cap where applicable, then on a saturated target award only 10% of that clamped bonus. The personal timer starts on completed impact (including a full resist); interruption has the native cancellation penalty. Claim shared saturation only on positive unsaturated damage. Never double-apply resistance or bypass a phase floor. Probes set the Invocation element on completion; earth is the initial fallback. If several elements tie in Survey show all tied elements. |
| Valkyrie | An interrupt is the native cast termination attributed to damage from the engaged hostile. Store caster, spell, interrupt sequence and deadline. Do not treat movement, user cancel, Silence, death, finishing, insufficient MP or changing target as interrupts. First Escort atomically claims the retry; refund only actual MP spent. |
| Channeler | No conduit cast on another Channeler already maintaining a channel. At ally cast start reserve the single benefit and snapshot native cast time before applying the discount. Break Link is always available to its owner. If the ally cancels, release the link and do not pay a completion refund. Solo self-link immediately exits the holding stance and applies only the one-spell MP discount for 8s. |
| Royal Tactician | A cast that actually applies or refreshes an eligible effect opens the matching order. Slow and Paralyze open Advance, Blind and Silence open Recompose. For the first successful Dispel before any order has been issued, default to Advance. Recompose consumes only on the next completed cost-bearing non-instant spell; never refund over the amount paid. |
| Scarlet Weaver | Yin and Yang are mutually exclusive and persistent through an encounter until switched. Default to Yang on first activation at Lv10. Switching while already in that aspect is a no-op. Disallow changes during cast/JA lock; snapshot aspect at actual damage resolution. Physical and magical WS use the existing WS system without the aspect multiplier. Maintaining one side is a valid optimal response to a stable resistance profile. |
| Trickster / Bandit | Process the original resolved WS once if any primary-target hit lands. Stronger existing Attack Down remains intact; do not consume Trickster's lock on an ineligible existing status. Bandit requires Defense Down already present before the WS resolves. A WS cannot create the opening and refund itself. Distinguish successful defense-lowering weapon/bolt proc from a resisted one in the starter tutorial. |
| Phantom / Skyborn | Phantom earns evasion hate only on enemy regular melee outcomes marked miss/evade, excluding parry, block, image absorption and damage-nullification. For Dare, define unavoidable as a landed hostile magical or breath damage event; never consume the guard on a normal melee hit. Skyborn's guard window checks the first qualifying direct enemy action targeting the Dragoon; apply its reduction to that action's damage against the Dragoon only. A multi-hit move is one event. Landing occurs at window expiry or after consuming the reduction, whichever comes first. Keep target and hate list during both stages. |
| Oathbreaker / Reaper | Vows can change only while disengaged and absent from hostile hate lists. Clear a pending retaliation on enemy death/target change. Count only damage actually lost by the player for Absolve's HP threshold. Reaper's new recovery window supersedes the previous one and resets its regular-round counter; multiple subhits in one round count once. Finality consumes its window only on a landed recovery strike, and an ordinary resolved miss still starts personal recast. |
| Scourge | One curse slot per enemy globally. If a new curse resists, leave any existing curse active. A hard-immunity fallback applies only if that same attack category has no active Scourge reduction. Famine fallback suppresses the next eligible non-scripted self-heal by half its normal percentage; it never creates mitigation on a party member. |
| Sniper / Lancer | Snapshot attacker start position, original target, zone and sequence. Sniper defaults to firing at 3s before Lv50 and 4s from Lv50; a second press at 3–4s releases the shorter shot. One completed shot can consume one ammo through the ordinary ammunition/recycle path. Lancer cannot be used as free travel. Require valid path, living claimed enemy and legal landing before relocating. Resolve the attack from the landing point using recorded approach band. |
| Arcane Archer | Select element by six explicit menu options sharing one recast. No extra gear swap required. Direct spells and native elemental SC events qualify; a single action may claim only once. An existing mark is replaced only by a newly landed arrow; remove this archer's prior mark on another target. |
| Nightblade / Archivist | Both use the enemy's server action sequence. A seal expires on completion/cancel or 8s. For Nightblade's mismatch retry spend no resources and set only the 3s retry. Archivist uses a completed hostile action ID, source spawn and recipient; categorize physical/magical/breath using engine metadata. Scripted HP setters and unavoidable kill flags bypass pages. If a move has multiple magical elements, exact action ID still controls. |
| Warmage | Assess Prey returns the least-resistant legal damage types from the target's current mitigation tables. A match exists for every tied minimum. Give the two starter variants explicit blunt/piercing categories for this Soul. Assess has one selected enemy, expires at the stated deadline, and tests actual type of the cast at resolution. Do not allow bonus on a sword hit, a WS, a self buff or a missed spell. A Soul-converted area spell selects exactly one target before damage is applied. |
| Untamed | Match living master, current jug instance, active action sequence and the same engaged enemy on both sides. An offensive Ready hit (including physical or magical native jug attacks) counts only on positive delivered damage. Native jug moves keep their existing Ready charge costs. The implementation must verify that raising pet TP influences the chosen jug's real action; if Ready eligibility is charge-based, leave charges native and apply the permitted offensive TP effect to native Ready potency, never synthesize a second pet attack. |
| Beastspeaker | Family recognition uses a valid local monster-family row. Pick the weakest physical type using local resistance, ties as in card. Actor cap is per attacking party member per exposure, normal multiattack subhits in one round claim at most once. The +8–12% applies on the first qualifying actual hit in a qualifying round. |
| Primalist / Herald | Starter elemental avatar defaults to Ifrit; Carbuncle also available. Each may use a Soul-local single-target starter Rage that deals native level-scaled pact damage of the avatar's element; if no suitable native damaging pact exists, use the character-level tier-I elemental reference with pet magic stats, 8% master max MP and normal Rage recast. Light uses Banish I as its reference. No permanent avatar flags. At 30 select two additional prime avatars outside combat via profile choice, default Shiva and Garuda. At 50 loan all six prime avatars. Native unlocked avatars remain available as listed on each card. Accord eligibility snapshots in-range party when cast; a member must remain alive in the same party/zone. A pet and master share one claim. Team rewards never multiply a pact's extra Soul damage. |
| Diviner | Axis is the straight segment from stationary anchor to caster. Project ally onto segment, clamp to endpoints, compare 2D distance against width, then check vertical difference and zone. Recall ends it. Shift reanchors at the caster so the segment is temporarily inactive until the caster moves at least 3y. With two active lines, leaving the stronger line restores the weaker one on the next sample. |
| Terramancer | Snapshot original target ID, spawn generation and zone; disallow target replacement. Eruption is 2D distance to original point ≤3y and absolute vertical difference ≤3y. Shallow/Deep share one outstanding fault; reject an attempted replacement without cost. Sample final target position at fuse expiry. Target death or claim loss cleans up the fault. |

## First-playtest interpretation

For the new caster comparisons, “least resistance” uses the target's native relative resistance or damage-type coefficients, not a random spell resist roll; equal affinities are all valid. Use an ordinary boss with one known favorable element and a second boss with uniform resistances. In mixed contingencies publish the condition in the HUD so players can act on it. Initial percentage modifiers are additive only where the card explicitly says so. Recording the base and final contribution makes it possible to tune the unique mechanic without redesigning its loop.

For Untamed, the native Ready **effectiveness** at 10 and 75 is a release dependency. If the installed engine neither spends pet TP nor uses it for Ready potency, keep the staged TP return for compatibility and make the first real offensive Ready within 8s after a qualifying master WS gain +10/12/14/16% ordinary Ready damage, once, in place of any derived TP-potency bonus. Implement this as a timed action qualification; do not create a second hit, more Ready charges or a stack meter. Both partners retain ordinary attack damage and death risk.
